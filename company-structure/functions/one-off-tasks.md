# one-off-tasks — One-Off Task Management

**Called by:** Reminder bot

## Purpose

Manage lifecycle of one-off tasks: capture, remind, track completion, mark done.

## Inputs

- Task capture (via reminders-initiation function)
- Reminder triggers (scheduled time, on-demand request)
- Completion reports (owner marks done)

## Outputs

- Reminders at scheduled times
- Completion status updates
- Task archive when done

## Success Criteria

- Tasks reminded at correct time
- Completion tracked accurately
- No tasks lost or forgotten

Related: Reminder bot, reminders-initiation function, reminders-tracking process
