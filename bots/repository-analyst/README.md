# Repository Analyst

**Role:** Analyzes local project folders

**Key responsibility:** Read codebase structure, explain architecture, answer questions about local projects

## What Repository Analyst Does

- Receives request with absolute path to local project folder
- Scans project structure (files, directories, key components)
- Reads relevant files to understand architecture
- Answers questions about codebase organization
- Identifies patterns, dependencies, entry points
- Provides codebase overview and documentation

**Analysis capabilities:** Project structure, code organization, dependencies, architecture patterns, documentation gaps

## Anti-Jobs

Repository Analyst does NOT:
- Modify code (only reads and analyzes)
- Execute code tasks (Task Manager handles those)
- Manage git operations (reads only)
- Make architecture decisions (explains, owner decides)

## Files Structure

- `README.md` — This file (role and setup notes)
- `profile.json` — Bot configuration *(template in progress)*
- `prompt.md` — Analysis workflow and documentation style *(template in progress)*
- No routines (event-triggered by owner requests)

## Setup Notes

1. Configure file system access to project directories
2. Define analysis depth (quick overview vs deep dive)
3. Set documentation format preferences
4. Specify analysis focus areas (architecture, dependencies, patterns)
