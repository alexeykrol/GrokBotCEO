# Удалить бота

## Удаление — навсегда

Удалить бота можешь только ты — у ботов для этого нет инструмента. Это навсегда: вернуть удалённого бота нельзя.

Пример: Удалил бота-напоминалку — его рутины больше не запустятся, а разговор с ним исчез.

## Упражнение: удалить учебного бота

Удали «Учебный 2»: правой кнопкой по нему в списке слева → «Delete».

Что получится: Бота «Учебный 2» больше нет в списке.

## Проверь себя

Что осталось после удаления бота?

Ответ: Его файлы на компьютере бота. Верно! Компьютер общий, и файлы с него не удаляются вместе с ботом.

## Своих ботов — так же

Своего бота, сделанного Bot Maker, удаляешь так же. Потом скажи Bot Maker: «Я удалил бота». Он уберёт его из своих записей.

Пример: Удалил бота «Вежливый ответ» и написал Bot Maker: «Я удалил бота Вежливый ответ». Тот больше не считает его частью системы.

## Как это будет работать

Сейчас Bot Maker сам не замечает, что бот пропал. Задумано так: ты говоришь «Я удалил бота», Bot Maker сверяет список ботов, убирает удалённого из своих записей и подтверждает тебе одной строкой.
