# Teaching Materials

Topic-specific guides for common questions. Your bot's mentor skill reads these files when your question matches a topic.

## Available Topics

- [bots.md](bots.md) — How bots work, roles, and communication
- [processes.md](processes.md) — Process lifecycle and triggers
- [protocols.md](protocols.md) — Rules bots follow
- [customization.md](customization.md) — Adapting the system to your needs

## How to Use

Ask your bot questions naturally. The mentor skill will find the relevant topic file and use it to answer.

Examples:
- "How do bots communicate?" → reads bots.md
- "What triggers a process?" → reads processes.md  
- "Can I change schedules?" → reads customization.md
